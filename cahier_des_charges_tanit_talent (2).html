Aperçu du Projet

Tanit Talent AI est un écosystème de recrutement natif pour le cloud, conçu pour connecter intelligemment les candidats aux employeurs en Tunisie et à l'international. La plateforme exploite l'Intelligence Artificielle pour analyser les CVs, calculer des scores de compatibilité et suggérer automatiquement les meilleures offres.

Le nom Tanit s'inspire de la déesse punique protectrice de Carthage, symbole de force et de guidance — une métaphore parfaite pour une plateforme qui guide les talents vers leur destinée professionnelle.

Utilisateurs & Rôles

👤 Candidat
  • Créer et gérer son profil
  • Uploader son CV (PDF)
  • Consulter les offres (emploi/stage)
  • Postuler à des offres
  • Voir son score IA de compatibilité
  • Recevoir des suggestions personnalisées
  • Suivre le statut de ses candidatures
  • Recevoir notifications (email + app)
🏢 Employeur
  • Créer et gérer le profil entreprise
  • Publier des offres (emploi/stage)
  • Consulter les candidatures reçues
  • Voir les scores IA des candidats
  • Accepter ou refuser des candidatures
  • Filtrer par compétences / score
  • Contacter les candidats retenus
  • Tableau de bord analytics
⚙️ Administrateur
  • Gestion des utilisateurs
  • Modération des offres
  • Tableau de bord statistiques globales
  • Gestion des catégories / compétences
  • Supervision du microservice IA
  • Logs système et monitoring
🤖 Système IA
  • Parser le CV du candidat
  • Extraire les compétences (NLP)
  • Calculer un score de 0 à 100
  • Matcher offres ↔ candidats
  • Générer des recommandations
  • Mise à jour des scores en temps réel

Stack Technique

⚛️ Frontend
  • React 18 + Vite (build ultra-rapide)
  • Tailwind CSS (utility-first styling)
  • Shadcn/ui (composants accessibles)
  • React Router v6 (navigation SPA)
  • React Query (cache & fetching API)
  • Zustand (state management léger)
  • Framer Motion (animations)
  • React Hook Form + Zod (validation)
🟩 Backend
  • Node.js 20 LTS
  • Express.js (API REST)
  • Prisma ORM (interface PostgreSQL)
  • JWT + bcrypt (authentification)
  • Multer (upload fichiers CV)
  • Nodemailer (emails transactionnels)
  • Socket.io (notifications temps réel)
  • Joi / Zod (validation données)
🐘 Base de Données
  • PostgreSQL 16 (SGBDR principal)
  • Prisma Migrations (versionning)
  • Redis (cache sessions & scores)
  • Tables : users, candidates, employers
  • offers, applications, skills, scores
  • pg_trgm (recherche textuelle)
🐍 Microservice IA (Python)
  • FastAPI (serveur API Python)
  • spaCy + HuggingFace (NLP/CV parsing)
  • scikit-learn (scoring & matching)
  • PyMuPDF (extraction PDF)
  • Communication via REST HTTP
  • Docker container isolé

Planning des 8 Semaines

Semaine 1 — 2
🏗️ Setup & Architecture
Initialisation du monorepo, configuration Docker, mise en place PostgreSQL + Prisma, structure Express.js, scaffolding React + Tailwind, CI/CD GitHub Actions de base.
Semaine 2 — 3
🔐 Authentification & Profils
Module auth JWT (inscription/connexion), gestion des rôles (Candidat/Employeur/Admin), pages profil, upload CV avec Multer, validation Zod.
Semaine 3 — 4
💼 Gestion des Offres & Candidatures
CRUD des offres d'emploi/stage, système de candidature avec lettre de motivation, filtres de recherche avancés, suivi du statut (pending/accepted/rejected).
Semaine 4 — 5
🤖 Microservice IA — Score & Matching
Développement FastAPI Python, parsing CV avec spaCy/PyMuPDF, extraction de compétences NLP, algorithme de scoring 0-100, API de matching offre↔candidat.
Semaine 5 — 6
📊 Dashboards & Notifications
Dashboards candidat et employeur avec graphiques (Recharts), notifications temps réel via Socket.io, emails automatiques via Nodemailer, suggestions IA affichées.
Semaine 6 — 7
⚙️ Back-Office Admin & Sécurité
Panel administrateur complet, modération des offres/utilisateurs, logs système, rate limiting, protection CSRF, audit sécurité OWASP.
Semaine 7 — 8
🚀 Tests, Optimisation & Déploiement
Tests unitaires Jest (couverture ≥70%), tests E2E Playwright, optimisation performances, déploiement Docker sur Railway, documentation API Swagger, recette finale.
📌 Jalons Clés
✅ Fin S2 : Auth fonctionnelle
✅ Fin S4 : Candidature end-to-end
✅ Fin S5 : Score IA opérationnel
✅ Fin S8 : Livraison production

Schéma Base de Données PostgreSQL

-- ═══════════════════════════════════════
-- 🗃️ SCHÉMA TANIT TALENT AI — PostgreSQL
-- ═══════════════════════════════════════

CREATE TABLE users (
id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
email VARCHAR(255) UNIQUE NOT NULL,
password_hash TEXT NOT NULL,
role ENUM('candidate','employer','admin'),
is_active BOOLEAN DEFAULT TRUE,
created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE candidates (
id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
user_id UUID REFERENCES users(id),
first_name, last_name VARCHAR(100),
cv_path TEXT, skills TEXT[],
ai_score FLOAT DEFAULT 0, location VARCHAR(100)
);

CREATE TABLE offers (
id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
employer_id UUID REFERENCES employers(id),
title VARCHAR(255) NOT NULL,
type ENUM('job','internship'),
required_skills TEXT[], salary_range VARCHAR(100),
status ENUM('open','closed','draft') DEFAULT 'open'
);

CREATE TABLE applications (
id UUID PRIMARY KEY, candidate_id UUID REFERENCES candidates(id),
offer_id UUID REFERENCES offers(id),
ai_match_score FLOAT, cover_letter TEXT,
status ENUM('pending','accepted','rejected') DEFAULT 'pending',
applied_at TIMESTAMP DEFAULT NOW()
);
Indexation recommandée : Index sur offers.type, applications.status, candidates.ai_score, offers.employer_id pour des recherches performantes. Utiliser pg_trgm pour la recherche textuelle full-text sur les titres d'offres et compétences.
